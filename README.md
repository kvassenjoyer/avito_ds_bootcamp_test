# Генерация кандидатов для поиска услуг

Решение подбирает до 50 объявлений для каждого запроса с помощью символьного TF-IDF и косинусной близости.

В проекте есть четыре варианта:

1. `baseline` — TF-IDF только по запросу и заголовку;
2. `text` — добавляет параметры и начало описания;
3. `history` — добавляет до 10 известных объявлений для совпавших запроса и категории;
4. `location` — актуальный вариант: берёт 200 текстовых кандидатов, добавляет небольшой бонус при совпадении локации и возвращает лучшие 50. После этого применяется история.

Результаты на leaderboard: `0.259640`, `0.297040`, `0.299320` и `0.360793` соответственно.

Файлы `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` нужно положить в `data/`.

```bash
python -m pip install -r requirements.txt
python run.py --variant location --output answer.csv
```

Проверка готового файла:

```bash
python scripts/check_submission.py answer.csv
```

Полная генерация занимает несколько минут; желательно 16 ГБ оперативной памяти.
