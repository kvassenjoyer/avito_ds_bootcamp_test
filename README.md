# Генерация кандидатов для поиска услуг

Первая версия решения использует символьный TF-IDF с косинусной близостью. Поисковый запрос сравнивается с заголовками объявлений. Символьные n-граммы устойчивы к словоформам и небольшим опечаткам в коротких запросах.

Результат на проверке: `Recall@50 = 0.259640`.

Файлы `benchmark_queries.parquet` и `benchmark_items.parquet` нужно положить в `data/`. Запуск:

```bash
python -m pip install -r requirements.txt
python run.py --output answer.csv
```
