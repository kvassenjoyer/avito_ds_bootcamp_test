# Генерация кандидатов для поиска услуг

В работе сравниваются две версии символьного TF-IDF с косинусной близостью.

Первая версия сравнивает запрос только с заголовком объявления. Во второй используются заголовок, первые 300 символов параметров и первые 500 символов описания. Заголовок и запрос повторяются два раза, чтобы увеличить вес основных слов.

Результаты на проверке:

- TF-IDF по заголовкам: `Recall@50 = 0.259640`;
- TF-IDF по тексту: `Recall@50 = 0.297040`.

Файлы `benchmark_queries.parquet` и `benchmark_items.parquet` нужно положить в `data/`. Запуск второй версии:

```bash
python -m pip install -r requirements.txt
python run.py --variant text --output answer.csv
```

Для запуска первой версии передайте `--variant baseline`.
