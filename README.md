# Генерация кандидатов для поиска услуг

Решение подбирает до 50 объявлений для каждого поискового запроса с помощью символьного TF-IDF и косинусной близости.

В работе сравниваются три версии: поиск только по заголовку, поиск по заголовку с параметрами и частью описания, а также расширенный поиск с историей выбранных объявлений. В финальном варианте история добавляет до 10 известных объявлений для совпавших запроса и категории. Решение работает локально и не использует внешние API.

Результаты на проверке:

- TF-IDF по заголовкам: `Recall@50 = 0.259640`;
- TF-IDF по тексту: `Recall@50 = 0.297040`;
- TF-IDF по тексту с историей: `Recall@50 = 0.299320`.

Файлы `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` нужно положить в `data/`. Запуск актуальной модели:

```bash
python -m pip install -r requirements.txt
python run.py --variant history --output answer.csv
```

Проверить готовый файл можно командой:

```bash
python scripts/check_submission.py answer.csv
```

Полная генерация занимает несколько минут; желательно 16 ГБ оперативной памяти.
